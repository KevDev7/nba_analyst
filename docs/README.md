# Project Docs

This folder is intentionally split between current operating docs and archived
project history.

## Start Here

- `pipelines/README.md` is the operational front door for raw/bronze, silver,
  gold, quality, and serving pipeline work.
- `pipeline-refactor-and-quality-layer-plan.md` records the completed pipeline
  refactor plan and execution notes.
- `query-model.md`, `grounded-planning.md`, `analysis-runtime.md`, and
  `answer-synthesis.md` describe the live assistant execution path.
- `supported-ontology-graph.md`, `ontology-shape.md`, and
  `family-ontology-backed-standard.md` describe current ontology/planner
  boundaries.
- `software-future-work.md`, `semantic-object-roadmap.md`, and
  `semantic-construction-refactor-plan.md` track forward-looking product or
  architecture work.

## Historical Docs

Completed milestone PRDs, implemented feature plans, and old batch logs live
under `archive/`. They are useful context, but they are not current operating
contracts.

Current behavior should be checked against code, tests, registry metadata,
pipeline runbooks, and the live contract docs above before relying on archived
notes.
